# 🥬🌽 Projeto PI Grupo 14 – Sabor do Campo

## 📌 Contexto

Este projeto é a continuação do sistema ERP desenvolvido no 4º módulo, voltado para a empresa familiar **Sabor do Campo**.

Nesta etapa, será desenvolvido um aplicativo mobile focado no controle de estoque de produtos hortifrúti, inicialmente couve e milho.

---

## 🚨 Problema

Atualmente, o controle de estoque é feito de forma manual ou parcialmente digital, o que pode gerar:

- Falta de controle preciso de entradas e saídas
- Perda de mercadorias
- Dificuldade de acompanhamento em tempo real
- Riscos de prejuízo financeiro

---

## 👥 Público-Alvo

- Empresa Sabor do Campo
- Responsáveis pelo estoque
- Gestores da produção e vendas

---

## 🎯 Objetivo

Desenvolver um aplicativo mobile integrado ao conceito do ERP, permitindo:

- Registrar entrada de produtos (couve e milho)
- Registrar saída/venda
- Atualizar estoque automaticamente
- Visualizar saldo disponível
- Melhorar a organização e gestão da empresa

---

## 🔄 Relação com o Projeto Anterior

Este projeto expande o ERP já desenvolvido, adicionando uma solução mobile para facilitar o controle operacional do estoque.

---
